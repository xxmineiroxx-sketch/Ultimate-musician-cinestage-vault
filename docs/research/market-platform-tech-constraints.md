# PLATFORM & TECHNICAL CONSTRAINTS — Musician Apps (iOS/Android, verified Aug 2026)

## 1. PLATFORM/SDK SNAPSHOTS

**Spotify platform (iOS/Android/Web API).** Mobile SDKs = *app-remote only*: the SDK talks to the installed Spotify app, which owns playback, networking, caching; the third-party app never touches audio (no PCM, no effects, no offline). Requires Spotify app installed; Premium required for on-demand track playback. Both repos live (not archived) as of Aug 2026: `spotify/ios-sdk` actively maintained (last push 2026-06), `spotify/android-sdk` quiet since 2024-08. The legacy in-app streaming SDK is gone (old `ios-streaming-sdk` repo removed). No in-app Spotify audio playback exists on mobile, period. [ios-sdk](https://github.com/spotify/ios-sdk), [android-sdk](https://github.com/spotify/android-sdk)
**Web API, Nov 27 2024 changes:** apps in development mode (and all new apps) lost access to Audio Features, Audio Analysis, Recommendations, Related Artists, Featured/Category Playlists, 30-sec preview URLs in multi-get, and algorithmic/editorial playlist content. [blog](https://developer.spotify.com/blog/2024-11-27-changes-to-the-web-api)
**Quota modes (current docs):** dev mode = **max 5 allowlisted users** (owner must be Premium); extended quota = unlimited users + higher rate limits, but **since May 15 2025 only organizations may apply** — requires legal business entity, launched service, **≥250k MAU**, company-email application; review up to 6 weeks. Rate limits: rolling 30-s window, 429s. [quota-modes](https://developer.spotify.com/documentation/web-api/concepts/quota-modes), [rate-limits](https://developer.spotify.com/documentation/web-api/concepts/rate-limits)
**ToS/Policy (v10, eff. May 15 2025):** bans creating derivative works of Spotify Content (stems are derivative works); bans feeding Spotify Content to ML/AI models; bans stream-ripping; bans **mixing/segue/overlap of Spotify audio with any other audio**; bans syncing to visuals; Premium-only streaming; **commercial use prohibited for Streaming SDAs** (no selling the app, no IAP/e-commerce, no ads on a Streaming SDA — only Non-Streaming SDAs may monetize); caching limited to metadata/art + time-limited Premium downloads. [terms](https://developer.spotify.com/terms), [policy](https://developer.spotify.com/policy)

**Apple Music platform (MusicKit + Apple Music API).** Third-party iOS apps CAN: full-track catalog playback for Apple Music subscribers, catalog search, library read/add (corroborated by djay's App Store listing: "Access to over 100 million songs… Apple Music subscription"). CANNOT: no PCM/buffer access — playback is delegated to the system player, there is **no public API to route Apple Music audio into AVAudioEngine** (no tap/effects/EQ on the stream — consistent across Apple docs; exact engineer confirmation unverified here); no DRM-free access, no offline export, no recording ("No recording available for streamed songs" — djay). Apple Music streams are FairPlay DRM; Media Services Terms: personal non-commercial use only, "you may not tamper with or circumvent any security technology," no modifying Content. MusicKit is Apple-platforms + JS only — **no Android MusicKit playback SDK** (Android = REST API catalog/previews only). [musikit](https://developer.apple.com/documentation/musikit), [applemusicapi](https://developer.apple.com/documentation/applemusicapi), [media-terms](https://www.apple.com/legal/internet-services/itunes/us/terms.html). No MusicKit policy shifts found for 2024–2026 (unverified for minor API additions).

**iOS audio stack.** AVAudioEngine/AVAudioSession: buffer 64–256 frames @48 kHz = 1.3–5.3 ms per buffer (math); pro-audio practice = 64–128-frame I/O buffers. App Review rules that bite: **2.5.4** background modes only for intended purposes (audio playback is a legit background mode — verified verbatim); **2.4.2** no excessive battery drain/heat (sustained Neural Engine load is review-relevant); **3.1.1** IAP required to unlock digital features; **5.2.3** (paraphrase) bars saving/converting/downloading media from third-party sources (Apple Music, Spotify, YouTube…) without explicit authorization. [guidelines](https://developer.apple.com/app-store/review/guidelines/)

**Android audio stack.** AAudio/Oboe (C++, API 16+ via OpenSL ES fallback, AAudio API 27+): lowest latency needs `PerformanceMode::LowLatency` + high-priority data callback; Exclusive mode bypasses the mixer. Fragmentation is the tax: HAL buffers commonly 96–512 frames, sample rates 44.1/48 kHz, per-device variance; the low-latency "fast mixer" path rejects effects (EQ/reverb/bass-boost kill the fast track). Android CDD: `audio.low_latency` = output ≤45 ms; `audio.pro` = round-trip ≤20 ms — while musicians need ~10 ms. Recent: API 36 adds compressed stream formats (MP3/AAC/Opus passthrough); API 37 adds routing-changed callbacks instead of hard disconnects. [oboe](https://github.com/google/oboe), [fullguide](https://raw.githubusercontent.com/google/oboe/main/docs/FullGuide.md), [latency-doc](https://developer.android.com/ndk/guides/audio/audio-latency)
**Play rules (Android 14+):** manifest FGS type `mediaPlayback` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` permission; Play Console declaration per FGS type incl. description + **demo video**; `mediaProcessing` FGS type covers time-consuming transcoding (stem export); full-screen intents restricted to alarm/calling apps by default since Jan 22 2025. [play-fgs](https://support.google.com/googleplay/android-developer/answer/13392821)

**Exemplar apps (the licensing workaround in practice).** Moises (iOS/Android/desktop; 75M users; 4.7★, 27K ratings; app 138.5 MB): AI stems, chord detection, lyrics, metronome, pitch/speed, collaborative setlists — **import-only sources** (Google Drive, Dropbox, iCloud, public URL, local files; YouTube links accepted in-app, as of 2025); upload → server-side processing → download stems; Premium $5.99/mo or $39.99/yr, Pro $29.99/mo (Hi-Fi models, 180-min uploads, VST). No Spotify/Apple Music separation anywhere. [appstore](https://apps.apple.com/us/app/moises-the-musicians-app/id1515796612), [play](https://play.google.com/store/apps/details?id=ai.moises). Algoriddim djay (iOS/macOS/Watch/Vision; PRO $6.99/mo, $49.99/yr): **Neural Mix = real-time on-device stem isolation** (vocals/drums/instrumentals; patented, e.g. US 10,887,033) — explicitly **"not available with Apple Music or Spotify"**; streams can't be recorded; Spotify integration back in the current listing (as of v5.6.8, Aug 2026), plus Apple Music, TIDAL (DJ extension), SoundCloud, Beatport/Beatsource. [appstore](https://apps.apple.com/us/app/djay-dj-app-ai-mixer/id450527929), [neural-mix](https://www.algoriddim.com/neural-mix)

## 2. TABLE STAKES 2026
- Assume streaming audio is a **black box**: app-remote control (Spotify) or system-player playback (Apple Music); build DSP only on user-owned/imported files.
- Premium/subscription-gated playback on both services; background audio + lock-screen/Now-Playing controls expected.
- Offline = only your own processed assets (stems, charts); no caching streamed audio beyond metadata.
- On Android: ship Oboe/AAudio with runtime buffer/latency detection; declare mediaPlayback FGS + Play Console video.
- Monetization: IAP on iOS; Spotify-sourced apps effectively cannot be sold (policy), so Spotify features are lead-gen at best.

## 3. EMERGING / AI-FORWARD DIFFERENTIATORS
- **Real-time on-device stem separation is proven but proprietary**: djay Neural Mix runs live on iPhone Neural Engine — but only on local files/DJ-licensed catalogs. Open models lag: Demucs htdemucs ≈1.5× track duration on desktop CPU (ft variant 4× slower; 3–7 GB GPU RAM) → offline-batch feasible on high-end phones, true real-time needs lighter/distilled models. [demucs](https://github.com/facebookresearch/demucs)
- AI chords/lyrics/metronome shipped by Moises (cloud).
- Android API 36/37 audio additions (compressed passthrough, routing callbacks); spatialization flags (API 32).
- Latency budget for live stem mixing: ~10 ms round-trip target; achievable on iOS (64-frame buffers) and on `audio.pro`-flagged Android only.

## 4. USER/DEV PAIN POINTS
- **Spotify devs:** Nov 2024 endpoint removals killed hobby/utility apps (no audio-features = no BPM/key analysis of catalog); dev-mode 5-user allowlist caps beta testing; orgs-only + 250k-MAU extension bar locks out indie musicians' tools (community backlash widely reported; specific threads unverified here).
- **Moises users:** processing requires upload wait (not instant/local); export formats/quality paywalled (WAV desktop-only; Hi-Fi in Pro).
- **djay users:** Neural Mix greyed out exactly on the streaming libraries users want; no recording of streamed mixes.
- **Android:** inconsistent latency/glitches across devices force per-device tuning (Google's own latency doc: buffer sizes vary 96–512 frames, clocks drift).
