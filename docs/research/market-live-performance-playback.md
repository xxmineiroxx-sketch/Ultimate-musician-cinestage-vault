# LIVE PERFORMANCE PLAYBACK / BACKING TRACKS — Competitive Benchmark (Aug 2026)

## 1. PRODUCT SNAPSHOTS

**Prime (Loop Community)** — iOS/iPadOS 15+ and macOS; free Basic tier + paid plans (Standard/Plus shown on site; App Store notes also reference "Prime Pro"/"Prime Pro Plus" tiers — exact monthly prices not published on pages I could fetch, **unverified**). Free tier: 300MB uploads, LC track library; paid tiers: 500GB–1TB cloud, 20–40 team members. Core: unlimited stem mixer (mute/solo/volume), key/tempo change, section loop/jump with jump-time quantization, transitions (crossfade/auto-advance/overlap), AutoPan (click/cues L, tracks R), dynamic click & spoken cues (EN/ES/PT), setlists with cloud sync/share, MIDI mapping (incl. Looptimus), MIDI out (PC/CC/notes) for lyrics/lights, multi-out via audio interfaces with global routing. **2024–26 additions:** v8.0 Tonic Pad Player (Sunday Sounds collab), v8.1 Loop Connect → Sunday Keys control + WorshipTools Presenter/Charts + CCLI auto-report, "Prime MD" AI workflows + custom band cues ("build it up / drums out / vocals only"), monthly pad presets. v8.3.5 (Jul 29, 2026). 4.7★, ~2K App Store ratings.

**Ableton Live 12** — macOS/Windows. Live 12.0 shipped Mar 5, 2024; current **12.4 (May 5, 2026)**. Pricing (verified in Ableton shop HTML): **Intro $99 / Standard $349 / Suite $749**, rent-to-own Suite **$31.21/mo × 24**; 30-day trial. Live-rig staples: Session View scene launching, tempo/meter maps, Tempo Following (follows a live drummer's audio), warping, 256 I/O, full MIDI out, MTC/MIDI Clock, **Ableton Link** (only product here with Link), Max for Live. **2024–26 additions:** 12.1 (Oct 2024) Auto Shift, Drum Sampler; 12.3 **Stem Separation** (Suite only, powered by Music.AI) + Splice integration; 12.4 **Link Audio** (network audio between devices), Learn View, user tagging. Not a purpose-built tracks app — no setlist mode, guide cues, or performer lyric view out of the box.

**Gig Performer** (Deskew) — macOS + Windows. Current **Pro 5.2.2 (May 2026)**; 5.0 released May 25, 2024; **Essentials** tier added Jul 2025. Pricing: **Pro $169 single-OS / $199 both; Essentials $59**; perpetual license (never expires), 5 activations, upgrades $29–$129. Plugin host (VST2/3, AU) with wire-based routing, widgets/front panels, songs/setlists, patch persist (no audio gap on switch), ChordPro chart display + auto-scroll lyrics, streaming audio file player (backing tracks from disk, low RAM), predictive loading, OSC, GPScript, GP Relayer (share audio/MIDI with DAWs), MIDI Finger Tap (tap through MIDI file = humanized guide track). Pro-user testimonials (Santana/Elton John/Megadeth touring personnel). Backing-track playback exists but is secondary to plugin hosting.

**Playback (MultiTracks.com)** — iOS/iPadOS 15.6+, **Mac (macOS 12.5+, with Dante, up to 32 outputs, expanded MIDI)**. Current **Playback 8.6.1 (Aug 6, 2026)**; Mac version is recent in the 8.x cycle (exact launch date **unverified**). Pricing: **Intro free; Premium $9.99/mo billed annually ($14.99/mo IAP monthly); Live Bundle $29.99/mo annually** (adds Cloud Pro 1TB uploads, 30 team seats, 14,000+ premade lyric production cues, 500+ song pads); weekly Rentals for 24,000+ master multitracks. Key/tempo change (12 keys), dynamic click with subdivisions, arrangement editing with dynamic guide cues, section loop/infinite loop/live re-order, fader/pad automation, live crossfade, Pad Player, MIDI cues + MIDI/keyboard mapping, MIDI Clock, **SMPTE/LTC out**, **PlayAudio 12 redundancy**, SmartRouting/MultiOuts (10 buses iOS / 32 Mac), Playback Remote (multi-device Wi-Fi control), Playback Sync→ChartBuilder auto-scroll, Planning Center setlist import, ProPresenter templates. 4.8★, 4.3K ratings.

**Stage Traxx 4** (Peter Dikant) — iPad/iPhone (iOS 16.6+), macOS 13.5+, visionOS. v4.0 launched recently (grace-period free upgrade covers ST3 purchases from Dec 2025 → **released early 2026**, exact date unverified); current **4.0.18 (Aug 3, 2026)**, v4.1 in beta per release notes. Pricing: **free (6-song limit); $29.99 one-time unlock incl. 12 months of new features (perpetual fallback); $14.99 upgrade from ST3**. 32 tracks/song, 16 output buses, per-track 4-band EQ, AUv3 hosting (iOS), dedicated click, mute groups, DCA faders; time-coded lyrics/chords (markdown, autoscroll incl. LRC), one-tap transpose, PDF charts + annotation, external screen; audio regions (loop/pause/skip, live/MIDI-triggered rearranging); embedded MIDI in lyrics (PC/CC/Note/SysEx), MTC (25/30fps) + MIDI Clock out, Bluetooth & network MIDI; Network Sessions (band-wide lyric/playback sync + wireless remote control); queue setlists, autoplay (gapless continuous performance); reliability: double-tap play protection, **dedicated failover output signal**, auto-save, backup/restore. 4.8★, 254 ratings. Dominant with solo/duo/cover/wedding acts (see Reddit evidence).

**One Man Band** (Jos Maas) — iPad/iPhone **$29.99** (free Lite). Real-time auto-accompaniment arranger (Yamaha PSR/Tyros style files), MIDI in/out to keyboard, soundfont player, customizable pads, MIDI file record — *not* a stem player. **Effectively unmaintained: v1.2, June 2018; 3.6★, 11 ratings.** Windows version exists historically but official site is defunct (**unverified/legacy**). Include only as a low-end solo-act reference point.

## 2. TABLE STAKES 2026
- Free entry tier; iPad + Mac (Windows only via Live/GP/OMB-legacy); fully offline playback of downloaded tracks.
- Per-stem mixer with mute/solo; separate click + spoken guide cues (AutoPan L/R is the worship default); key/tempo change (12 keys) without re-import.
- Section markers with loop/jump/live re-order; setlists with auto-advance, crossfade/gapless transitions, per-song transition settings.
- Multi-output USB interface routing with pre-assigned buses; MIDI out (PC/CC) to drive lyrics (ProPresenter/Presenter), lights, patch changes; MIDI/Bluetooth foot-pedal & controller mapping (AirTurn, Looptimus, Morningstar).
- Cloud setlist sync + team sharing; ambient pad player; ecosystem hooks (Planning Center, ChartBuilder, CCLI).
- Safety: double-tap stop protection, backup/restore, large-setlist performance (Playback 8.6.1 added setlist paging).

## 3. EMERGING / AI-FORWARD DIFFERENTIATORS
- **On-device stem separation:** Ableton Live 12.3 (Suite, Music.AI) — the only one here; aimed at stem *creation*, not live mixing.
- **AI workflows in worship:** Prime MD (AI-assisted cues/arrangement) + Loop Connect (Presenter/Charts/Sunday Keys/CCLI auto-report) — Loop Community is productizing the whole worship stack.
- **Networked band sync:** ST4 Network Sessions (host/client lyric + playback sync, wireless remote); Playback Remote; Playback Sync→ChartBuilder. Bandleader/member role split is emerging here, none match a true role-based collaboration model yet.
- **Redundancy as a feature:** Playback + PlayAudio 12 hardware failover; ST4 failover output signal; GP "instant hardware replacement" remapping. Pro rigs now expect a documented failover story.
- **Pro audio networking:** Playback Mac = Dante + 32 outs; Ableton 12.4 Link Audio (LAN audio); SMPTE/LTC (Playback) vs MTC (ST4) vs both-plus-CV (Live).
- **Ableton Link:** only Live ships it; iOS tracks apps rely on MIDI Clock/MTC.
- **Apple Watch / spatial audio / streaming-service (Spotify/Apple Music) integration: none of the six ship these** (as of pages fetched; absence unverified for Watch).
- **Licensing shift:** ST4's "pay once, 12 months of features, keep forever" model vs Playback/Prime subscriptions vs GP/Ableton perpetual.

## 4. USER PAIN POINTS (Reddit/forums)
- **Playback:** r/worshipleaders user ~1 yr after switching from Prime: "frequent glitches — settings resetting, songs not transferring, sync drops, network issues — 3 of 4 Sundays"; losing trust despite responsive support; weighing switch back to Loop.
- **Prime + Playback (both):** click/tracks "not keeping time" over iPad→M32 IEM rig (clock/source-config class of issue).
- **Stage Traxx:** iPadOS multichannel interface quirks (UMC404HD rear playback outs silent though X32 works); MTC-only output complicates ProPresenter timelines for users migrating from Ableton's LTC-audio workflow; ST3 lyric highlight is line-level only (users want word-level); users report Bluetooth pedals (AirTurn BT500S, iRig BlueBoard) unreliable and actively seek wired controllers.
- **Ableton Live:** steep learning curve + high cost cited by worship users (also Loop Community's own positioning — biased source); general consensus it's overpowered/fragile for simple tracks duty without a dedicated operator.
- **Gig Performer:** community thread "Strange MIDI and Audio Problems with 2 GP Instances After Upgrade to GP 5" (Dec 2024); stem playback is a secondary feature vs its plugin-host core.
- **One Man Band:** abandoned (2018), 3.6★ — data-point that unmaintained gig apps die on the store.
