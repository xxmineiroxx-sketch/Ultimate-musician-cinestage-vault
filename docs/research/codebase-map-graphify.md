## 3. Playback system (deep dive)

**Two parallel playback architectures, both on `expo-av` — no `react-native-track-player` in current code** (present in the Dec-2025 MERGED_REPO copy, dropped by June 2026):

1. **Team app engine** — `vault/src/services/audioEngine.js` (730 lines, singleton): multi-stem playback = one `Audio.Sound` per stem, all started via `Promise.all` for rough sync. Features: click/guide track slots, per-stem volume/mute (`setTrackVolume`/`setTrackMute`), **scenes** (`applyScene` mutes stems per scene), **A–B loop regions** (100 ms sync-monitor interval, jump-back when within 110 ms of loop end, 180 ms debounce), `panicStop` (10-step volume fade), `clickOnlyMode`, conductor command bus (`PLAY/PAUSE/SEEK/LOOP_SECTION/CLICK_ONLY/PANIC_STOP/APPLY_SCENE`), remote-URL caching to `up_practice_audio/` via expo-file-system. Audio session: `playsInSilentModeIOS`, `staysActiveInBackground: true`. **No drift correction** beyond the initial simultaneous start; routing (`iem/foh/stream`) is a state stub — comment admits "In real implementation, this would route audio".
2. **Admin app engine** — `mobile/audioEngine/` modular: `Loader.js` (12 s load timeout, FNV-hash remote→cache `um_audio_cache/`, YouTube URLs refused), `Conductor.js` (**actual drift correction**: master track = click→guide→first stem; `syncTracks()` re-aligns any track drifting >150 ms), `TimingEngine.js` (bar/beat clock, 4-beat look-ahead `md-ai-cue` events), plus `EventBus`. `setMixerState()` maps mixer UI to per-stem volumes.

**Gapless/crossfade:** No sample-accurate gapless. What exists: transition modes `CUT/CROSSFADE/OVERLAP` in `wavePipelineEngine.js`; "Smooth Crossfade" song transitions in `RehearsalScreen` (navigates + restarts); pad crossfades (`liveSequencer.startSequencePad` ~900 ms, `spontaneousPad.crossfadeTo`); in `SetlistRunnerScreen` "crossfade" is a **visual** opacity fade between charts, not audio.

**Offline:** Confirmed twice over — per-URL audio caches in both engines, plus `offlineServicePack.js` (downloads full service bundles: audio/stems/charts into `ultimate_playback_service_packs/`, manifest in AsyncStorage) with a `smoke-offline-pack.js` test script.

**Background audio:** Both apps declare `UIBackgroundModes: ["audio"]` in app.json and set `staysActiveInBackground`.

**Stem mixing at playback time:** Yes — stems are separate `Audio.Sound` objects mixed live by volume/mute; `roleStemRouter.resolveRoleFilteredTracks` filters which stems a role hears (e.g., drummer gets click+drums).

**Stem pipeline:** `stemJobService.js` — local file upload via `POST /sync/stems/upload` (sync worker), submit via `/sync/stems/submit`, dispatch `POST {CINESTAGE_URL}/jobs/process` with `jobType: STEM_SEPARATION`, `separationMethod: "generative_infilling"`, 12 target stems (`lead_vocal, bgv, acoustic_guitar, electric_guitar, piano, synth, bass, kick, snare, cymbals, toms, other`), harmony separation, `preserveSpatial`; polls 4 s/8 s up to ~30 min.
