# System Overview

## A. ULTIMATE MUSICIAN (Admin Command Center)
- **Role:** Centralized asset and fleet management.
- **Stack:** React Native (Expo) + Next.js Web.

## B. ULTIMATE PLAYBACK (Musician's Interface)
- **Role:** High-performance, low-latency playback engine.
- **Stack:** React Native (Expo) + Custom Native Audio.

## C. CINESTAGE (The AI Signal Processor)
- **Role:** High-concurrency cloud infrastructure.
- **Stack:** Cloudflare Workers + Python (FastAPI/Modal).

## D. ULTIMATESYNCSERVER (The MIDI Sentinel)
- **Role:** Local MIDI bridge with cloud failover.
- **Stack:** Node.js + Rust.
